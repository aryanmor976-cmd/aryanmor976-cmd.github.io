PROJECT

Student Expense Tracker

Python & MySQL Expense Management Application

GitHub

Overview

Student Expense Tracker is a menu-driven application built with Python and MySQL to record, manage, and analyze student expenses. The application stores expense records in a MySQL database and provides a simple command-line interface for everyday expense management.

Key Features

  • Add and store expense records
  • View all recorded expenses
  • Search expenses by category
  • Update existing expense records
  • Delete expense records
  • Calculate total, average, and count of expenses
  • Generate category-wise expense summaries
  • Generate monthly expense summaries
  • Validate user input through the application

Technologies Used

Python MySQL SQL MySQL Connector/Python python-dotenv VS Code

Database

The application uses a MySQL database named student_expense_tracker with an expenses table for persistent storage. Expense records include the date, category, description, and amount.

What I Built

  • Designed a structured database for storing expense information.
  • Connected Python with MySQL for database operations.
  • Implemented CRUD operations through a menu-driven interface.
  • Added SQL-based expense analysis for category-wise and monthly spending.
