PROJECT 02

Student Expense Tracker

Python & MySQL Expense Management Application

About the Project

Student Expense Tracker is a command-line application developed with Python and MySQL to make everyday expense management more organized for students.

The application allows users to record, view, search, update and delete expense records while keeping the data stored in a MySQL database. It also provides spending summaries that make it easier to understand expenses by total amount, category and month.

I built this project to strengthen my understanding of Python programming, SQL, database connectivity and CRUD operations by applying them to a practical problem.

Application Preview

The Problem

Students often have small daily expenses spread across different categories, making it difficult to keep track of where money is being spent. A simple system was needed to store expenses consistently and provide useful summaries without depending on manual calculations.

My Approach

I designed the application around a menu-driven interface so that each operation could be accessed directly from the command line. Python handles the application logic and user interaction, while MySQL provides persistent storage for the expense records.

The database layer was separated from the main application logic, making the project easier to understand and maintain. SQL queries are used not only for CRUD operations but also for calculating spending summaries.

SQL-Based Analysis

SQL is also used to turn stored expense records into useful summaries. The project uses aggregation and grouping queries to analyze spending.

SUM()

Calculates total spending.

AVG()

Calculates the average expense.

COUNT()

Counts the number of expense records.

GROUP BY

Generates category-wise spending summaries.

Database Design

The application uses a MySQL database named student_expense_tracker. Expense information is stored in the expenses table.

01

ID

INT primary key with auto-increment.

02

Expense Date

DATE field for the expense date.

03

Category

VARCHAR field for expense category.

04

Description

Optional description of the expense.

05

Amount

DECIMAL field for the amount spent.
