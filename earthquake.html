PROJECT 01

Earthquake Detector

Arduino-Based Vibration Alert System

About the Project

The Earthquake Detector is an Arduino-based vibration-monitoring prototype designed to detect sudden ground vibrations and provide an alert using an LED and buzzer.

How It Works

The SW-420 vibration sensor detects vibration and sends a signal to the Arduino Uno. The Arduino processes the sensor input and activates the alert components when vibration is detected.

Key Features

Vibration Detection

Detects sudden vibrations using the SW-420 vibration sensor.

Real-Time Processing

The Arduino Uno processes the sensor signal when vibration is detected.

Visual Alert

An LED provides a visual indication when vibration is detected.

Sound Alert

A buzzer provides an audible alert when vibration is detected.
